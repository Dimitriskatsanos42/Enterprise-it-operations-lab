# Στρατηγική Backup

## Στόχοι

| Μετρική | Στόχος |
|---|---|
| RPO (Recovery Point Objective) | Μέγιστη απώλεια δεδομένων 24 ωρών |
| RTO (Recovery Time Objective) | 4 ώρες για DC01, 8 ώρες για file server |
| Διατήρηση backup | 30 ημέρες κυλιόμενα, μηνιαίο archive διατηρείται 1 έτος |

## Πρόγραμμα

| Συχνότητα | Τύπος | Εύρος | Διατήρηση |
|---|---|---|---|
| Καθημερινά (02:00) | Incremental | Όλοι οι servers (DC01, SRV01, MON01) | 14 ημέρες |
| Εβδομαδιαία (Κυριακή 01:00) | Full | Όλοι οι servers | 30 ημέρες |
| Μηνιαία (1η του μήνα, 00:30) | Full (Αντίγραφο Archive) | Όλοι οι servers | 12 μήνες |

## Τι Γίνεται Backup

| Server | Δεδομένα |
|---|---|
| DC01 | System State (βάση δεδομένων AD, SYSVOL, registry), δεδομένα ζώνης DNS |
| SRV01 | Όλα τα shares τμημάτων (Finance, HR, Sales, IT, Management) |
| MON01 | Ρύθμιση monitoring και ιστορικά δεδομένα |

## Κανόνας 3-2-1

- **3** αντίγραφα δεδομένων (παραγωγή + τοπικό backup + αντίγραφο εκτός τοποθεσίας/cloud)
- **2** διαφορετικά μέσα/τοποθεσίες αποθήκευσης (τοπικό NAS + αποθήκευση cloud/εκτός τοποθεσίας)
- **1** αντίγραφο διατηρείται εκτός τοποθεσίας, απομονωμένο από το παραγωγικό δίκτυο (προστατεύει από ransomware που στοχεύει συνδεδεμένο backup storage)

## Επαλήθευση Backup

Εκτελείται μηνιαία **δοκιμαστική επαναφορά (test restore)** σε απομονωμένο VM για επιβεβαίωση ότι τα backups είναι πράγματι επαναφέρσιμα — ένα backup που δεν έχει δοκιμαστεί ποτέ δεν είναι αξιόπιστο backup. Τα αποτελέσματα (επιτυχία/αποτυχία, χρόνος επαναφοράς) καταγράφονται.

| Μήνας | Έγινε Δοκιμαστική Επαναφορά | Αποτέλεσμα | Χρόνος Επαναφοράς |
|---|---|---|---|
| (παράδειγμα) Ιαν 2026 | Επαναφορά System State, DC01 | Επιτυχία | 52 λεπτά |

## Backup System State (DC01) — PowerShell / wbadmin

```powershell
wbadmin start systemstatebackup -backupTarget:E: -quiet
```

## Backup File Server (SRV01)

Γίνεται μέσω Windows Server Backup με στόχο έναν αφιερωμένο τόμο backup, με προγραμματισμένη εργασία αντιγραφής που αναπαράγει το σετ backup σε αποθήκευση εκτός τοποθεσίας/cloud μετά από κάθε επιτυχή εκτέλεση.
