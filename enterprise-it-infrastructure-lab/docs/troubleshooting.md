Αυτό είναι το σημείο εκκίνησης για κοινά προβλήματα IT support. Ξεκινήστε εδώ, και μετά ακολουθήστε τους συνδέσμους προς το αναλυτικό άρθρο knowledge base ή το έγγραφο troubleshooting.

## Γενικά Πρώτα Βήματα (Οποιοδήποτε Ticket)

1. **Αναπαραγωγή ή επιβεβαίωση του προβλήματος** — μην υποθέτετε· ζητήστε ακριβές κείμενο σφάλματος/screenshot αν είναι δυνατόν
2. **Ελέγξτε πρώτα το προφανές** — είναι πράγματι ενεργή η υπηρεσία/server; (`Test-Connection`, ελέγξτε το dashboard MON01)
3. **Ελέγξτε πρόσφατες αλλαγές** — υπήρξε αλλαγή GPO, Windows Update, ή αλλαγή λογαριασμού τις τελευταίες 24-48 ώρες που συσχετίζεται;
4. **Απομονώστε το εύρος** — αφορά έναν χρήστη, ένα τμήμα, ή όλους; Αυτό περιορίζει αμέσως τη βασική αιτία (μεμονωμένος λογαριασμός vs. πρόβλημα υποδομής)
5. **Τεκμηριώστε καθώς προχωράτε** — βήματα που δοκιμάστηκαν, αποτελέσματα, ώστε το ticket να είναι χρήσιμο ακόμα κι αν χρειαστεί escalation

## Μονοπάτι Escalation

L1 (Helpdesk) → L2 (IT Support/Sysadmin) → IT Manager, για οτιδήποτε αφορά:
- Πιθανό περιστατικό ασφάλειας
- Διακοπή σε επίπεδο υποδομής
- Οτιδήποτε απαιτεί αλλαγές επιπέδου Domain Admin
