# Baseline Ασφάλειας Windows (Hardening)

## Εύρος Εφαρμογής

Ισχύει για όλα τα domain-joined endpoints (μέσω GPO) και τους servers (μέσω αυστηρότερου baseline ειδικά για servers). Δες [`../active-directory/gpos.md`](../active-directory/gpos.md) για τα GPOs που επιβάλλουν αυτές τις ρυθμίσεις.

## Baseline Client Endpoints

| Έλεγχος | Ρύθμιση | Σκεπτικό |
|---|---|---|
| Λογαριασμός Guest | Απενεργοποιημένος | Αφαιρεί έναν γνωστό, συχνά αχρησιμοποίητο λογαριασμό που στοχεύουν πρώτα οι επιτιθέμενοι |
| Τοπικός λογαριασμός Administrator | Μετονομασμένος + διαχειριζόμενο password μέσω LAPS (παραγωγικό περιβάλλον) | Αποτρέπει την επαναχρησιμοποίηση διαπιστευτηρίων σε πολλά μηχανήματα αν διαρρεύσει ένα τοπικό admin password |
| Windows Firewall | Ενεργό σε όλα τα profiles, default deny εισερχόμενης κίνησης | Μειώνει την επιφάνεια επίθεσης από lateral movement |
| SMBv1 | Απενεργοποιημένο | Παλιό, ευάλωτο πρωτόκολλο (κατηγορία exploits όπως EternalBlue/WannaCry) |
| AutoRun/AutoPlay | Απενεργοποιημένο | Μπλοκάρει μια συνηθισμένη μέθοδο διανομής malware μέσω USB |
| Removable storage | Μπλοκαρισμένο (εκτός τμήματος IT) | Μειώνει τον κίνδυνο διαρροής δεδομένων |
| Screen lock | 10 λεπτά αδράνειας, password στο resume | Περιορίζει την έκθεση αν μια συσκευή μείνει χωρίς επίβλεψη |
| Windows Update | Κεντρικά διαχειριζόμενο, δεν επιτρέπεται αναβολή πέρα από το χρονικό παράθυρο πολιτικής | Εξασφαλίζει ότι τα patches εφαρμόζονται εντός γνωστού SLA |
| Περιττές υπηρεσίες (Remote Registry, Telnet κ.λπ.) | Απενεργοποιημένες | Μειώνει την επιφάνεια επίθεσης |

## Baseline Servers (Επιπλέον)

| Έλεγχος | Ρύθμιση | Σκεπτικό |
|---|---|---|
| RDP | Περιορισμένο σε πηγή VLAN 10 (Management), μόνο GG_IT_Admins | Αποτρέπει lateral πρόσβαση RDP από endpoints χρηστών |
| Audit policy | Καταγράφονται logon/logoff, διαχείριση λογαριασμών, πρόσβαση αντικειμένων | Επιτρέπει διερεύνηση περιστατικών και τεκμήρια συμμόρφωσης |
| Windows Firewall | Μόνο ρητοί κανόνες allow για τις απαραίτητες υπηρεσίες | Στάση default-deny |
| Τοπικοί λογαριασμοί admin | Ελαχιστοποιημένοι, χρησιμοποιούνται domain λογαριασμοί όπου είναι δυνατόν | Μειώνει τα αυτόνομα διαπιστευτήρια προς διαχείριση |

## Επαλήθευση Baseline

Η συμμόρφωση ελέγχεται δειγματοληπτικά με `gpresult /h report.html` σε δείγμα μηχανημάτων από κάθε τμήμα, και κεντρικά μέσω `Get-GPOReport` σε όλα τα συνδεδεμένα GPOs. Οποιοδήποτε μηχάνημα δείχνει απόκλιση από το baseline διερευνάται (συνήθως προκαλείται από χειροκίνητη παράκαμψη μιας πολιτικής από τοπικό admin, ή GPO που απέτυχε να εφαρμοστεί λόγω προβλημάτων συνδεσιμότητας κατά το logon).

## Παράδειγμα Πριν → Μετά

| | Πριν το Hardening | Μετά το Hardening |
|---|---|---|
| Λογαριασμός Guest | Ενεργός | Απενεργοποιημένος |
| SMBv1 | Ενεργό (default Windows σε παλιότερα builds) | Απενεργοποιημένο |
| Firewall (Domain profile) | Default ρυθμίσεις Windows, ευρεία εισερχόμενη allow | Default deny, μόνο ρητοί κανόνες allow |
| RDP | Ενεργό για όλους τους ταυτοποιημένους χρήστες | Περιορισμένο σε Management VLAN + GG_IT_Admins |
| Removable storage | Χωρίς περιορισμούς | Μπλοκαρισμένο για τμήματα εκτός IT |
