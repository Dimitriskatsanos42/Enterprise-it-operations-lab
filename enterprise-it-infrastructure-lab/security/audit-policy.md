# Πολιτική Ελέγχου (Audit Policy)

## Σκοπός

Το logging είναι χρήσιμο μόνο αν καταγράφει τα events που έχουν σημασία για διερεύνηση ασφάλειας και συμμόρφωση, χωρίς να παράγει τόσο θόρυβο που να μην τα εξετάζει κανείς. Αυτό το έγγραφο ορίζει τι καταγράφεται, πού πηγαίνουν τα logs, και πώς αντιμετωπίζονται τα περιστατικά.

## Κατηγορίες Ελεγχόμενων Events (Domain Controllers)

| Κατηγορία | Ρύθμιση | Γιατί |
|---|---|---|
| Account Logon | Επιτυχία + Αποτυχία | Εντοπισμός προσπαθειών brute-force, ασυνήθιστων μοτίβων σύνδεσης |
| Account Management | Επιτυχία + Αποτυχία | Παρακολούθηση δημιουργίας/διαγραφής χρηστών, αλλαγών συμμετοχής σε groups |
| Logon/Logoff | Επιτυχία + Αποτυχία | Συσχέτιση με lockouts (Event ID 4740) και ασυνήθιστες ώρες πρόσβασης |
| Object Access | Αποτυχία (στοχευμένα σε ευαίσθητα shares) | Εντοπισμός μη εξουσιοδοτημένων προσπαθειών πρόσβασης στα shares Finance/HR |
| Policy Change | Επιτυχία + Αποτυχία | Εντοπισμός μη εξουσιοδοτημένης παρέμβασης σε GPO ή audit policy |
| Privilege Use | Αποτυχία | Εντοπισμός προσπαθειών χρήσης δικαιωμάτων που δεν έχει ένας λογαριασμός |

## Βασικά Event IDs που Πρέπει να Γνωρίζετε

| Event ID | Σημασία |
|---|---|
| 4624 | Επιτυχημένο logon |
| 4625 | Αποτυχημένο logon |
| 4740 | Lockout λογαριασμού (περιλαμβάνει τον υπολογιστή-πηγή — δες [KB-002](../it-support/knowledge-base/KB-002-account-lockouts.md)) |
| 4720 | Δημιουργήθηκε λογαριασμός χρήστη |
| 4726 | Διαγράφηκε λογαριασμός χρήστη |
| 4732 | Προστέθηκε μέλος σε security-enabled τοπικό group |
| 4728 | Προστέθηκε μέλος σε security-enabled global group |
| 5140 | Έγινε πρόσβαση σε network share |

## Διατήρηση Logs

Τα security event logs διατηρούνται για τουλάχιστον 90 ημέρες τοπικά, με κρίσιμα events να προωθούνται στον server monitoring (MON01) για μακροπρόθεσμη διατήρηση και συσχέτιση.

## Βασική Διαδικασία Αντιμετώπισης Περιστατικού

1. **Εντοπισμός** — επιβεβαίωση ότι το event είναι πραγματικό (όχι false positive) χρησιμοποιώντας τα σχετικά Event IDs παραπάνω
2. **Περιορισμός** — απενεργοποίηση του επηρεαζόμενου λογαριασμού (`Disable-ADAccount`) ή απομόνωση του επηρεαζόμενου μηχανήματος από το δίκτυο αν υποψιάζεται malware
3. **Διερεύνηση** — προσδιορισμός της έκτασης: ποια συστήματα/δεδομένα προσπελάστηκαν, ποιο χρονικό παράθυρο
4. **Εξάλειψη** — αφαίρεση της αιτίας (malware, ανάκληση compromised διαπιστευτηρίων, κλείσιμο του exploited μονοπατιού πρόσβασης)
5. **Ανάκτηση** — αποκατάσταση κανονικής πρόσβασης μόλις επιλυθεί το πρόβλημα, reset τυχόν εκτεθειμένων διαπιστευτηρίων
6. **Τεκμηρίωση** — συγγραφή αναφοράς περιστατικού: χρονολόγιο, βασική αιτία, επίλυση, και τι θα αποτρέψει την επανεμφάνιση

## Παρακολούθηση Προνομιακών Λογαριασμών

Οι αλλαγές συμμετοχής στο `GG_IT_Admins` (Event ID 4728/4732 σε αυτό το συγκεκριμένο group) αντιμετωπίζονται ως ειδοποιήσεις υψηλής προτεραιότητας — μια απρόσμενη προσθήκη σε προνομιακό group είναι ένα από τα πιο ξεκάθαρα σημάδια ενεργού compromise.
