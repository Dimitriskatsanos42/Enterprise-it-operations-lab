## Πρόβλημα

Ο χρήστης δεν μπορεί να εκτυπώσει στον εκτυπωτή του ορόφου Sales. Οι εργασίες εκτύπωσης μένουν στην ουρά και δεν ολοκληρώνονται ποτέ· δεν εμφανίζεται μήνυμα σφάλματος στην οθόνη.

## Βήματα Αντιμετώπισης

1. Ελέγχθηκε η κατάσταση τροφοδοσίας/δικτύου του εκτυπωτή — ο εκτυπωτής είναι online, απαντά σε ping στο 192.168.20.51
2. Ελέγχθηκε η ουρά εκτύπωσης στον υπολογιστή του χρήστη — 4 εργασίες κολλημένες, κατάσταση "Printing"
3. Ελέγχθηκε η υπηρεσία Print Spooler στον υπολογιστή του χρήστη — τρέχει
4. Ελέγχθηκε η υπηρεσία Print Spooler στον print server — **σταματημένη**
5. Εξετάστηκε το Event Viewer (Application log) στον print server — ο spooler κατέρρευσε λόγω αλλοιωμένου αρχείου driver μετά από πρόσφατο Windows Update

## Βασική Αιτία

Η υπηρεσία Print Spooler κατέρρευσε στον print server μετά από ενημέρωση driver, προκαλώντας συσσώρευση όλων των εργασιών εκτύπωσης του ορόφου Sales αθόρυβα (η πλευρά του client έδειχνε "Printing" αντί για σφάλμα).

## Επίλυση

1. Καθαρίστηκε η κολλημένη ουρά εκτύπωσης: `Get-PrintJob -PrinterName "Sales-Floor" | Remove-PrintJob`
2. Επανεκκινήθηκε η υπηρεσία Print Spooler: `Restart-Service -Name Spooler -Force`
3. Επανεγκαταστάθηκε ο driver εκτυπωτή από το τρέχον πακέτο του κατασκευαστή (όχι αυτό που έφερε το Windows Update)
4. Στάλθηκε δοκιμαστική εκτύπωση — επιβεβαιώθηκε ότι λειτουργεί
5. Ενημερώθηκαν οι υπόλοιποι χρήστες του ορόφου Sales ότι ο εκτυπωτής επανήλθε

## Προληπτική Ενέργεια

Προστέθηκε το `Spooler` στη λίστα παρακολούθησης του [`Service-Health-Check.ps1`](../../automation/Service-Health-Check.ps1) ώστε μια κατάρρευση του spooler να ενεργοποιεί αυτόματη προσπάθεια επανεκκίνησης πριν χρειαστεί να το αναφέρει κάποιος.
