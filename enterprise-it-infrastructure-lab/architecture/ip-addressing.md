# Πλάνο IP Addressing

## VLANs

| VLAN ID | Όνομα | Subnet | Gateway | Σκοπός |
|---|---|---|---|---|
| 10 | Management | 192.168.10.0/24 | 192.168.10.1 | Workstations IT admin, out-of-band management |
| 20 | Users | 192.168.20.0/24 | 192.168.20.1 | Endpoints εργαζομένων (DHCP) |
| 30 | Servers | 192.168.30.0/24 | 192.168.30.1 | Domain controller, file server, monitoring |
| 40 | Guest | 192.168.40.0/24 | 192.168.40.1 | Guest Wi-Fi, απομονωμένο |

## Στατικές Αναθέσεις (VLAN 30 — Servers)

| Hostname | Ρόλος | Διεύθυνση IP | Subnet Mask | DNS |
|---|---|---|---|---|
| DC01 | AD DS / DNS / DHCP | 192.168.30.10 | 255.255.255.0 | 127.0.0.1 |
| SRV01 | File Server | 192.168.30.20 | 255.255.255.0 | 192.168.30.10 |
| MON01 | Monitoring | 192.168.30.30 | 255.255.255.0 | 192.168.30.10 |

## Στατικές Αναθέσεις (VLAN 10 — Management)

| Hostname | Ρόλος | Διεύθυνση IP |
|---|---|---|
| ADMIN-PC01 | Workstation IT Admin | 192.168.10.10 |

## DHCP Scope (VLAN 20 — Users)

| Ρύθμιση | Τιμή |
|---|---|
| Εύρος Scope | 192.168.20.100 – 192.168.20.200 |
| Subnet Mask | 255.255.255.0 |
| Default Gateway | 192.168.20.1 |
| DNS Server | 192.168.30.10 |
| Διάρκεια Lease | 8 ημέρες |
| Εξαιρούμενο Εύρος | 192.168.20.1 – 192.168.20.99 (δεσμευμένο για υποδομή) |

## DHCP Scope (VLAN 40 — Guest)

| Ρύθμιση | Τιμή |
|---|---|
| Εύρος Scope | 192.168.40.50 – 192.168.40.250 |
| DNS Server | Δημόσιο DNS (1.1.1.1 / 8.8.8.8) — χωρίς πρόσβαση στο εσωτερικό DNS |
| Διάρκεια Lease | 4 ώρες |

## Δεσμευμένα Εύρη

Κάθε VLAN δεσμεύει τα `.1`–`.9` για gateways/network devices και τα `.250`–`.254` για μελλοντική υποδομή, αφήνοντας περιθώριο ανάπτυξης χωρίς ανάγκη επαναρίθμησης.
